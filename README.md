# 六子棋 · 本地棋室

**简体中文** | [English](README_EN.md)

在浏览器中玩六子棋，支持人机对弈和同机双人对弈。AI 直接使用 `FinalVersion.cpp` 中的 C++ 策略。

## 功能

- 15×15 棋盘，单人模式可选择执黑或执白。
- 双人模式在同一台电脑上轮流操作。
- 每方累计 10 分钟，支持预选确认、悔棋和重新开始。
- 显示落子记录、最近落子和获胜连线，支持键盘操作。

## 快速开始

需要 **Python 3.10+** 和支持 **C++17** 的编译器（g++、clang++ 或 c++），编译器需加入 `PATH`。无需安装第三方 Python 包。

下载或克隆仓库后，在项目根目录启动：

### Windows

双击 `start_game.bat`，或在 PowerShell 中运行：

```powershell
.\start_game.bat
```

### macOS

```sh
sh ./start_game.sh
```

尚未安装 C++ 编译工具时，执行 `xcode-select --install`。如需在 Finder 中双击启动，先执行一次 `chmod +x start_game.command`，之后双击 `start_game.command`。

### Linux

```sh
sh ./start_game.sh
```

Ubuntu / Debian 可通过以下命令安装依赖：

```sh
sudo apt update
sudo apt install python3 g++
```

首次启动会自动编译 AI，并打开 [http://127.0.0.1:8000](http://127.0.0.1:8000)。请保持服务窗口打开，按 `Ctrl+C` 关闭服务。如果浏览器未自动打开，可手动访问该地址。

端口被占用时，可指定其他端口：

```powershell
# Windows
.\start_game.bat --port 8001
```

```sh
# macOS / Linux
sh ./start_game.sh --port 8001
```

也可通过环境变量 `CXX` 指定编译器可执行文件。

## 玩法

1. 选择模式和执子颜色，点击“开始对局”。黑方首回合落一子，此后每回合落两子。
2. 点击棋盘交叉点预选，再次点击取消；选好后点击“确认落子”。预选期间继续计时。
3. 横、竖或斜向连成六子及以上获胜，无禁手。如果第一颗子已成六，可直接确认。满盘无人获胜则和棋。
4. 每方整局累计 10 分钟，不加秒、不暂停，超时判负。AI 计算、切换标签页和打开确认框时均继续计时。

悔棋优先清除预选；双人模式撤回最近一个完整回合，单人模式撤回最近一次玩家落子及随后的 AI 落子。AI 执黑时保留其开局。**悔棋不返还已消耗的时间。**

方向键移动焦点，`Enter`／空格预选或取消，`Esc` 清空预选。刷新页面会清空棋局；重开或切换模式、颜色会重置棋盘和时钟。

## 项目结构

| 文件 | 用途 |
| --- | --- |
| `FinalVersion.cpp` | C++ AI 策略，启动时直接编译 |
| `server.py` | 本地网页服务与 AI 调用 |
| `web/` | 棋盘界面、游戏规则和计时逻辑 |
| `start_game.*` | 各平台启动脚本 |
| `tests/` | 规则、计时与 AI 接口测试 |

游戏界面为简体中文，服务仅监听本机 `127.0.0.1`，双人模式不支持远程联机。AI 超时或返回非法落点时，网页会提示错误，可重试、悔棋或重新开始。
